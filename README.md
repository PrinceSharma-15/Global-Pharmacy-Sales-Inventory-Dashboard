Global Pharmacy Sales & Inventory Dashboard

About the Project:
This project is a Power BI dashboard created to analyze global pharmacy sales and inventory data. The goal was to transform raw sales data into meaningful insights that can help understand business performance across different countries, product categories, regions, and customer age groups.
To prepare the data, I used SQL for querying and analysis, and Power BI for data modeling, visualization, and dashboard design
#Dashboard Preview
[Dashboard](Pharmacy%20Sales%20Dashboard%20Snapshot.png)

# What This Dashboard Shows
- Total Sales
- Total Units Sold
- Average Unit Price
- Number of Countries
- Number of Product Categories
- Top 3 Best-Selling Categories
- Sales Trend by Year
- Sales by Region
- Sales by Customer Age Group

The dashboard also includes interactive filters for Year, Category, Region, and Age Group, allowing users to explore the data from different perspectives.

## Tools Used
- Microsoft SQL Server
- SQL
- Power BI
- Power Query
- DAX
- Microsoft Excel
# Key Insights
- The dashboard highlights the top-selling medicine categories.
- Sales performance can be compared across different regions.
- Yearly sales trends help identify business growth and decline.
- Customer purchasing patterns vary across different age groups.
- Interactive filters make it easy to explore the data.
